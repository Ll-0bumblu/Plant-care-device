# 🌱 Plant‑care‑device – Полный стек мониторинга растений

Веб‑приложение для сбора, хранения и визуализации данных с датчиков (температура, влажность воздуха, влажность почвы, освещённость).  
Проект включает:

- **Сервер** (Node.js + Express + SQLite) – REST API для работы с измерениями.
- **Клиент** (React + TypeScript + Vite) – интерфейс для просмотра графиков, настройки порогов и оповещений.
- **Прошивка ESP‑12E** – устройство на базе ESP8266, которое опрашивает датчики и отправляет данные на сервер.

## 🧰 Общие требования

- **Node.js** версии 18 или выше (рекомендуется LTS)

- **Arduino IDE** (для прошивки ESP)

## 🖥️ Сервер (Backend)

### 1. Установка и настройка

Перейдите в папку сервера и установите зависимости:

```bash
cd server
npm install
```

Создайте файл `.env` (опционально) для переопределения настроек:

```env
PORT=3000
HOST=0.0.0.0
DB_PATH=./sensor_data.db
```

| Переменная | Описание | Значение по умолчанию |
|------------|----------|-----------------------|
| `PORT`     | Порт сервера | `3000` |
| `HOST`     | Хост для прослушивания | `0.0.0.0` |
| `DB_PATH`  | Путь к файлу SQLite | `./sensor_data.db` |

### 2. Запуск

**Режим разработки** (с автоматической перезагрузкой):

```bash
npx nodemon app.js
```

**Продакшн**:

```bash
node app.js
```

После запуска сервер будет доступен по адресу `http://localhost:3000`.

### 3. База данных

SQLite-файл создаётся автоматически. Таблица `measurements` имеет структуру:

| Поле           | Тип      | Описание |
|----------------|----------|----------|
| `id`           | INTEGER  | Первичный ключ, автоинкремент |
| `deviceId`     | TEXT     | Идентификатор устройства |
| `timestamp`    | INTEGER  | Unix-время в миллисекундах |
| `temperature`  | REAL     | Температура (°C) |
| `humidityAir`  | REAL     | Влажность воздуха (%) |
| `soilMoisture` | REAL     | Влажность почвы (%) |
| `illuminance`  | REAL     | Освещённость (люкс) |

### 4. Документация API

Swagger UI доступен по адресу:  
👉 [http://localhost:3000/api-docs](http://localhost:3000/api-docs)

Там описаны все эндпоинты:

- `POST /api/measurements` – добавить измерение
- `GET /api/measurements` – получить список (с фильтрацией)
- `GET /api/measurements/latest` – получить последнее измерение
- `DELETE /api/measurements/{id}` – удалить измерение по ID

## 🎨 Клиент (Frontend)

### 1. Установка и запуск

Перейдите в папку клиента и установите зависимости:

```bash
cd client
npm install
```

Запустите в режиме разработки:

```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:5173`.  
Vite автоматически перезагружает страницу при изменениях.

### 2. Сборка и линтинг

**Сборка для продакшна**:

```bash
npm run build
```

**Предпросмотр собранного приложения**:

```bash
npm run preview
```

**Линтинг** (oxlint):

```bash
npm run lint
```

### 3. Основные возможности

- Отображение максимумов за сегодня в виде карточек.
- Графики динамики показателей за день (recharts).
- Настройка допустимых диапазонов для каждого параметра.
- Загрузка фото растения (хранится в `localStorage`).
- Оповещения (Snackbar) при выходе значений за пороги.
- Обновление данных каждую минуту (React Query).

### 4. Прокси для API

В `vite.config.ts` настроен прокси для запросов к серверу:

```ts
server: {
  proxy: {
    '/api': {
      target: 'http://localhost:3000',
      changeOrigin: true,
    },
  },
}
```

Если сервер запущен на другом порту или хосте, измените `target`.

## 📡 Прошивка ESP‑12E

### 1. Оборудование и подключение

- ESP‑12E (NodeMCU, Wemos D1 mini или аналогичный)
- Датчик DHT22 (температура/влажность)
- Аналоговый датчик влажности почвы (ёмкостный)
- Фоторезистор или модуль освещённости (аналоговый)

**Подключение пинов** (согласно коду `sketch_jul26c.ino`):

| Компонент               | Пин ESP8266 |
|-------------------------|-------------|
| DHT22 (сигнал)          | GPIO12 (D6) |
| Датчик почвы (питание)  | GPIO13 (D7) |
| Датчик почвы (сигнал)   | A0          |
| Датчик света (питание)  | GPIO14 (D5) |
| Датчик света (сигнал)   | A0          |

> ⚠️ Оба аналоговых датчика используют один пин A0, но включаются поочерёдно через управление питанием (power pin).

### 2. Настройка среды разработки

1. Установите Arduino IDE (1.8.x или 2.x).
2. В **Файл → Настройки** добавьте URL для менеджера плат:  
   `https://arduino.esp8266.com/stable/package_esp8266com_index.json`
3. В **Инструменты → Плата → Менеджер плат** установите пакет `esp8266`.
4. Выберите плату: **Инструменты → Плата → ESP8266 Boards → NodeMCU 1.0 (ESP-12E Module)**.

### 3. Установка библиотек

Через **Скетч → Подключить библиотеку → Управлять библиотеками** установите:

- `DHT sensor library` (Adafruit)
- `ArduinoJson` (версия **6.x**, не 7!)

### 4. Настройка параметров

Отредактируйте `sketch_jul26c.ino`:

```cpp
const char* ssid = "ВашWiFi";         
const char* password = "ВашПароль";     
const String serverUrl = "http://IP_сервера:3000/api/measurements";
```

Укажите реальный IP‑адрес компьютера, на котором запущен сервер (не `localhost`, т.к. ESP8266 его не увидит).

### 5. Компиляция и загрузка

1. Подключите ESP‑12E к компьютеру через USB.
2. Выберите правильный COM‑порт в **Инструменты → Порт**.
3. Нажмите **Загрузить** (→) в Arduino IDE.
4. Дождитесь сообщения _"Done uploading"_.

### 6. Калибровка датчиков

- **Влажность почвы**: в коде заданы `SOIL_DRY = 330` и `SOIL_WET = 280`.  
  Измерьте значения в сухой и мокрой почве и подставьте свои.

- **Освещённость**: выводится в процентах (0–100) после инвертирования (параметр `invert`).  
  При необходимости измените логику в классе `LightSensor`.

### 7. Проверка работы

Откройте **Инструменты → Монитор порта** (скорость 9600 бод).  
Плата будет подключаться к Wi‑Fi и каждые 60 секунд отправлять данные. В логах вы увидите:

- IP‑адрес, полученный от роутера;
- отправленный JSON;
- код ответа сервера.

## 🔄 Совместный запуск

1. Запустите сервер (на порту 3000).
2. Запустите клиент (на порту 5173) – он автоматически проксирует запросы к серверу.
3. Запитайте ESP‑12E – он начнёт отправлять измерения.
4. Откройте `http://localhost:5173` в браузере – данные появятся на графиках и в карточках.

Для проверки вручную можно отправить тестовый запрос через `curl`:

```bash
curl -X POST http://localhost:3000/api/measurements \
  -H "Content-Type: application/json" \
  -d '{"deviceId":"sensor-001","temperature":25.5,"humidityAir":60.0,"soilMoisture":45.0,"illuminance":300.0}'
```
